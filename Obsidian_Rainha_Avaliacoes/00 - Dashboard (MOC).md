# 👑 Rainha — Central de Avaliações de Excel

> [!info] Resumo do Projeto
> Sistema desktop autônomo (**Launcher + Instalador Único**) em **C# / .NET 10 Windows Forms** para aplicação segura de avaliações práticas de Microsoft Excel, garantindo proteção total dos templates originais e salvamento automático mesmo quando o candidato fecha o Excel sem salvar.
